# زَادَن | ZADEN — MVP 1.0

هذه النسخة مبنية كنسخة أولية مستقرة بأربع ميزات رئيسية فقط:

1. **الرئيسية واكتشاف المتاجر والمنتجات** — بحث وتصنيفات ومنتجات ومتاجر تجريبية.
2. **السلة** — إضافة المنتجات وتعديل الكمية وحساب الإجمالي.
3. **تأكيد الطلب** — تأكيد محلي مع الدفع عند الاستلام.
4. **الطلبات والتتبع** — قائمة الطلبات ومسار حالة الطلب.

يوجد أيضًا اختيار نوع الحساب (عميل، صاحب متجر، صاحب مطعم، مندوب) كجزء من الهيكل، لكنه لا يضيف ميزات تشغيلية جديدة في هذه النسخة.

## مهم
- لا توجد قاعدة بيانات أو API أو خرائط أو دفع إلكتروني في هذه النسخة.
- البيانات تجريبية ومحلية داخل التطبيق حتى لا تكون هناك أزرار وهمية مرتبطة بخدمات غير موجودة.
- المشروع يستخدم Flutter وDart فقط بدون حزم خارجية إضافية، لتقليل احتمالات أخطاء الاعتماديات.
- افتح مجلد `zaden` نفسه في بيئة Flutter/IDE، ثم نفّذ `flutter pub get` وبعدها التشغيل أو بناء APK.
